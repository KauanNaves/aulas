# aulas
    Aulas de POO do Curso em Vídeo usando a Linguagem Python.

## 05/11/2026 - ex001
    Primeiro exercício prático onde aprendi a declarar Classes e instanciar objetos das mesmas.
    Entendi a diferença de métodos de intância, atributos de instância e também a como declarar uma Classe e Objetos usando Python.


## 05/11/2026 - ex002
    Neste exercício aprendi a diferença entre Dunder Attributes e Dunder Methods, e também a como sobreescrever os Dunder Methods, como, por exemplo, o __str__().
    Aprendi também como funcionam as Docstrings das classes em python.

## 09/11/2026 - rich_extra
    Esta foi uma aula extra sobre a biblioteca rich, onde usamos para melhorar a visualização de informações ao executar nossos programas em python no terminal.
    Aprendi funcionalidades interessantes dessa biblioteca, como o print() permitindo mostrar cores e emojis de forma simples e rápida, a função inspect() melhorando a visualização de classes e objetos e a função install() que nos ajuda visualizar melhor qualquer erro dentro do nosso programa.
    Documentação: rich.readthedocs.io
